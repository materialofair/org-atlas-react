# 美光总部所在地的后道职能

美光将美国爱达荷州博伊西（Boise）列为公司总部。门户以明确标有 Boise 或 Boise Main Site 的岗位为依据。另收录带有「全球运营」标记的公司级职能。岗位记录反映公开职责，当前招聘状态、完整部门树和负责人的汇报关系仍需公司确认。[美光年报](https://investors.micron.com/static-files/7a1f8c6f-1ce9-4efe-bc6e-722b6b9c4550)

| 门户分组 | 公开职责与图形依据 |
| --- | --- |
| APTD 封装材料整合 | Boise 主园区岗位 JR103345 负责 HBM、3DS DRAM 等产品的材料路线图，与美国及亚洲团队和供应商合作。岗位举例包括临时键合膜及玻璃、硅载体，因此分别绘制里程碑、揭膜和支撑载体。[美光岗位记录](https://micron.wd1.myworkdayjobs.com/en-US/External/job/Director---Package-Materials-Integration--APTD_JR103345) |
| APTD 晶圆级工艺整合 | JR110875 面向晶圆级整合及重构基板。职责包括设计实验、综合测试与量测数据；经验要求列举晶粒偏移、翘曲等问题。图鉴使用位置偏差标记、弯曲剖面及实验矩阵。[美光岗位记录](https://micron.wd1.myworkdayjobs.com/en-US/External/job/Process-Integration-Engineer--APTD_JR110875) |
| DRAM 可测试性设计 | Boise 岗位 JR103405 在设计、产品工程和测试制造之间协作，开发测试架构，调试测试向量并改善测试时间和覆盖率。新增芯片观测支路与向量游标两种图形。[美光岗位记录](https://careers.micron.com/careers/apply?pid=42223048) |
| TSE 关键设备组（KEG） | JR110450 的地点为 Boise，服务范围为全球制造网络。该组开发、验证及部署探针台、测试机及探针卡，制定设备规格。探针卡用斜探针与焊盘表示，设备标准化用量规表示。[美光岗位记录](https://careers.micron.com/careers/apply?pid=44281038) |
| 新品供应计划 | Boise 的 NPO 供应计划岗位结合良率、周期、厂区负载与产能边界向制造端确认投产需求。它属于跨制造环节的配套职能，图鉴收录厂区负载和投产指令。[美光岗位记录](https://careers.micron.com/careers/apply?pid=44508070) |
| 全球运营 | 美光在 2017 年的公告中把全球封测运营与供应链履约、采购、质量等并列。此处引用历史公告说明业务范围。各厂具体产线和现任领导需独立核实。[美光全球运营公告](https://investors.micron.com/news/press-release/2017/Micron-Appoints-Manish-Bhatia-as-EVP-of-Global-Operations-10-16-2017/default.aspx) |
