# 长鑫存储后道职能与选图

图鉴入口为 `?view=icons&collection=cxmt`。八个分组按职责整理，覆盖集团披露的运营分工、DRAM 后道工序和招聘方向。负责人及上下级汇报关系没有在这些资料中给出。

## 谁负责运营

长鑫科技集团 2026 年半年报第 16 页分别介绍了封装、成品测试和模组加工测试。报告期内，芯片封装由集团研发技术、委外生产；测试以自主实施为主、外协为辅；模组加工测试同时由合肥子公司与外协厂商承担。[公司半年报，生产模式](https://static.cninfo.com.cn/finalpage/2026-08-29/1225529543.PDF#page=16)

| 报告中出现的部门或职能 | 实际工作 | 专题选图 |
| --- | --- | --- |
| 计划部门、生产部门 | 把生产需求分配给自有与外协工厂，安排产量并跟进交期。 | 分岔的计划单代表自测与委外分配，日期格与箭头代表交期跟踪。 |
| 外包管理 | 封装段称「外包管理部」，测试和模组段称「外包管理商务部」。职责涉及新外包商或项目评估导入，以及日常质量和交付。 | 厂房与准入勾用于项目导入，评分板用于质量交付考核。图鉴合并展示两处称谓。 |
| 后道采购部 | 商务谈判、签订合同、核对账单；报告在测试和模组段还列出订单交期跟进。 | 合同签字与双单据核对各用一枚图标，便于区分签约和结算。 |

## 后道工序与研发岗位

| 分组 | 有依据的活动与选图 |
| --- | --- |
| 晶圆测试（CP） | 工艺流程图列出直流参数、功能及裕度、晶圆修复和晶圆级老化。四项分别使用仪表、边界波形、绕行线路和晶圆热流。 |
| 芯片封装 | 减薄、切割、晶粒粘贴、打线和模封复用库中对应图形。成品植球新增带独立焊球的基板图标，用于与委外封装厂对接。 |
| 成品测试（FT） | 复用老化与性能分档图标，新增存储阵列与读写箭头表示核心存储测试。 |
| 模组加工与测试 | 分别使用模组装联与模组测试图标；自有和委外环节均可使用。 |
| 研发与产品验证 | 2027 届招聘简章列出封装设计开发、模组设计开发、产品系统测试研发、电性失效分析和产品质量与可靠性工程。新增模组布线图形，区分开发与装联。 |

工序依据为招股说明书「工艺流程图」，生产方式依据为半年报「生产模式」。研发职称来自长鑫署名、高校就业网刊载的招聘简章。[长鑫科技招股说明书](https://static.cninfo.com.cn/finalpage/2026-07-22/1225435990.PDF#page=162) · [半年报第 16 页](https://static.cninfo.com.cn/finalpage/2026-08-29/1225529543.PDF#page=16) · [长鑫科技 2027 届招聘简章](https://job.hust.edu.cn/zpinfo1/2405543.htm)
