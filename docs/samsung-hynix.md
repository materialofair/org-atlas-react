# 三星与 SK 海力士的后道运营选图

图鉴中的中文名称是按工作内容整理的导航分类。三星部分取自 DS 部门 TSP 公开招聘资料，SK 海力士部分取自公司招聘记录与员工访谈。岗位、工作任务和组织单元的粒度各不相同。两家公司各自的图标集合可在图鉴中筛选，每组标题附原始资料。

| 公司与职能 | 公开资料描述的职责 | 选图理由 |
| --- | --- | --- |
| 三星 TSP 生产管理 | 编制封装生产计划，调度瓶颈资源，分析成本并协调客户样品供应。[生产管理](https://www.samsung-dsrecruit.com/recruits/job_intro/testPackage_center/productionManagement.php) | 收窄的工位表示瓶颈，成本筹码和带箭头的样品盒分别表示成本分析与样品交付。 |
| 三星 TSP 采购 | 开发 OSAT 伙伴，管理安全库存及先进先出。[采购](https://www.samsung-dsrecruit.com/recruits/job_intro/testPackage_center/buy.php) | 两座工厂、库存下限、同向移动的料箱分别表示外协采购、安全库存、FIFO。 |
